# Matt, tired walk (archive, v1)

The first Ludo animation set for Matt (25 Nov 2026): walks in place seen from the side,
front and back for clothed, towel and boxers, plus a reach-forward from the side for
each. Prompted as "a tired man's steady walk", so his back and neck slump. Replaced
as the default by an upright walk; kept for scenes where Matt should look worn down.

Known: the clothed and towel front walks drift to three-quarter view, the boxers side
walk turns toward the camera. Each `.webp` is a sprite sheet (grid in animations.json),
`.gif` a preview, `.mp4` the source video. Model: Ludo Griffin (griffin-hd), 5 s.
1.5x upscaled sheets are added under `upscaled/` when ready.
