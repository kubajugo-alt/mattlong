# Matt in the trench coat: Ludo animations

Ludo animateSprite (griffin-hd, 36 frames, 6x6 sheets, looping, end frame locked to the start pose).
`coat-*.webp` are the raw sheets, `coat-*.mp4` previews. The demo strips in `demo/office-walk/sprites/`
are built from the walk sheets with `tools/pack_sprite.py`; `interact-side-strip.*` is the reach, packed the same way.
