# Matt, upright walk (current)

Ludo Griffin (griffin-hd) walks in place, seen from the side, front and back, for
clothed, towel and boxers (`walk3-*`): upright posture, straight back and neck, head
level; the start pose is also the end frame, so none drift off their angle. Plus the
reach-forward from the side for each state (`interact-*`, from the first set).
The slumped first set is in `../archive/matt-tired-v1/`. Each `.webp` is a sprite
sheet (grid in animations.json), `.gif` a preview, `.mp4` the source video.
